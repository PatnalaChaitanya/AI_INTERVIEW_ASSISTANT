# 🤖 AI Interview Assistant

An AI-powered interview practice application designed to help candidates improve their technical knowledge, communication skills, and interview confidence through interactive mock interviews and AI-generated feedback.

## 🚀 Overview

**AI Interview Assistant** provides an interactive interview environment where users can select different topics, answer interview questions using voice recording, and receive performance feedback.

The application features a modern, responsive interface with a clean dark theme, making interview preparation more engaging and accessible.

## ✨ Features

- **Multiple Interview Topics:** Practice different subjects, including:
  - Self Introduction
  - Generative AI
  - Python
  - English
  - HTML
  - CSS

- **Voice-Based Interview:** Record your answers using a microphone.
- **Interactive Interview Experience:** Practice with an AI interviewer named Natalie.
- **Question Tracking:** Track your progress through a five-question interview session.
- **AI-Powered Feedback:** Receive feedback on your interview performance.
- **Performance Scoring:** Get a score out of 5 based on your performance.
- **Improvement Suggestions:** Identify areas that need improvement.
- **Responsive UI:** Works across desktop and mobile devices.
- **Modern Design:** Gradient styling, animated elements, and a dark-themed interface.

```bash

```

### 2. Navigate to the Project Directory

```bash

```

### 3. Run the Application

Open the `index.html` file in your browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

## 🎯 How to Use

1. Open the AI Interview Assistant application.
2. Select an interview topic from the sidebar.
3. Click **Start Interview**.
4. Listen to the interviewer's question.
5. Click the microphone button and record your answer.
6. Submit your answer.
7. Continue until the interview is completed.
8. Click **Get Feedback** to review your performance.
9. Check your score, feedback, and improvement suggestions.
10. Start a new interview to practice another topic.
